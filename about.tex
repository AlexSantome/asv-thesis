\chapter*{About this manuscript} \label{sec:about}
\addcontentsline{toc}{chapter}{About this manuscript}

\begin{itemize}
    \item This dissertation was prepared using the 
        \href{https://web.mit.edu/thesis/tex/}{MIT thesis template}.

    \item This manuscript was written in \href{https://en.wikipedia.org/wiki/LaTeX}{LaTeX} using 
        \href{https://code.visualstudio.com/}{Visual Studio Code} editor on a Windows-based 
        workstation with \href{https://en.wikipedia.org/wiki/Windows_Subsystem_for_Linux}{Windows 
        Subsystem for Linux (WSL)}.

    \item Typesetting and compilation were performed with \href{https://www.tug.org/texlive/}{TeX 
        Live 2026} using \href{https://mgeier.github.io/latexmk.html}{latexmk (v4.88)} and the
        \href{https://www.luatex.org/}{luaTEX (v1.24.0)} engine.

    \item All graphs and data visualizations were generated using Python's 
        \href{https://matplotlib.org/}{matplotlib} library. Figures were subsequently assembled, 
        annotated, and arranged for publication using Microsoft PowerPoint.

    \item Bibliographic references were managed with \href{https://www.zotero.org/}{Zotero} and 
        exported in \href{https://retorque.re/zotero-better-bibtex/}{Better BibTeX} format. 

    \item Spelling, grammar, and stylistic consistency were reviewed using AI-assisted 
        writing tools, including \href{https://gemini.google.com/}{Google Gemini}. These tools were 
        used exclusively for language revision and editorial support. All technical content, 
        scientific analyses, results, interpretations, and conclusions were produced and verified 
        by the author.

\end{itemize}


Unless otherwise stated, all drawings, figures, simulations, analyses, and textual content 
presented in this dissertation were produced by the author.
